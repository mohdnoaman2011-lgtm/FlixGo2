# FlixGo (Flutter)

This folder holds the Dart code, assets and pubspec. The Android/iOS folders are generated by Flutter itself.

1. Install Flutter, then run inside this folder:

       flutter create . --project-name flixgo

   (it adds android/, ios/, web/ and keeps lib/, assets/ and pubspec.yaml; if it asks to overwrite pubspec.yaml or lib/main.dart, keep ours)
2. flutter pub get
3. flutter run

Downloads are simulated in start() inside lib/main.dart. Hook up your own download service there.
